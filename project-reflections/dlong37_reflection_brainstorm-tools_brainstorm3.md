# Reflection: brainstorm-tools_brainstorm3

brainstorm3 is the one project in this set with no inactivity gap at all. There are zero gaps of three or more months across roughly 15 years of history, the only project with that
distinction. Its pattern is cyclical via repeated spikes of high activity separated by quieter periods, but never a true lull.

Because there's no gap to interpret, there's no reason for inactivity or recovery to
discuss. What stands out instead is the scale and continuity of the project: 7,833
commits from 122 distinct authors, more than any other project here by a wide margin. That
profile (a large, sustained contributor base with continuous activity rather than
concentrated bursts tied to a single paper) reads much more like actively maintained
scientific infrastructure (a neuroimaging analysis toolbox) than the single-author,
publication-driven research code seen in most of the other nine projects.

**Current status:** Active (last GitHub commit 2026-09-15).
